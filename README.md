# ربات تلگرام برند AMON

ربات کامل فروش اکانت بازی، اشتراک VIP و سفارش وبسایت برای برند **AMON**.

## ویژگی‌ها

### کاربر
- جوین اجباری ۴ کانال (قبل از استفاده از ربات)
- خرید اکانت AMON GAME با استخراج خودکار کد از پیام/فوروارد
- خرید اشتراک AMON TRADE VIP (۸ میلیون تومان)
- سفارش وبسایت AMON NET
- ارسال رسید و پیگیری وضعیت سفارش
- سیستم پشتیبانی (تیکت)
- پروفایل، کد معرف، کد تخفیف
- راهنما و FAQ

### ادمین (`/admin`)
- پنل کامل مدیریت
- تأیید/رد رسیدها با دکمه
- ارسال اطلاعات اکانت (هر نوع محتوا: متن، عکس، ویس، فایل)
- مدیریت موجودی اکانت‌ها (افزودن/حذف/لیست)
- آمار فروش و کاربران
- ارسال پیام همگانی
- بلاک/آنبلاک کاربر
- تنظیم لینک کانال VIP
- مدیریت کدهای تخفیف

## نصب و اجرا (لوکال)

```bash
# نصب پکیج‌ها
pip install -r requirements.txt

# کپی فایل محیط
cp .env.example .env

# ویرایش .env و قرار دادن توکن ربات + کانال‌ها
# BOT_TOKEN=...
# ADMIN_IDS=8007177524
# VIP_CHANNEL_LINK=...
# CHANNEL_1=@YourChannel1
# CHANNEL_2=@YourChannel2
# CHANNEL_3=@YourChannel3
# CHANNEL_4=@YourChannel4

# اجرا
python bot.py
```

## دیپلوی روی Railway

1. یک پروژه جدید در Railway بسازید.
2. این فولدر `Robot` را به عنوان root directory آپلود یا از Git وصل کنید.
3. در Variables این‌ها را اضافه کنید:
   - `BOT_TOKEN` = توکن ربات از @BotFather
   - `ADMIN_IDS` = 8007177524 (یا چندتا با کاما)
   - `VIP_CHANNEL_LINK` = لینک واقعی کانال خصوصی
4. Deploy کنید. Railway به صورت خودکار `Procfile` را تشخیص می‌دهد.

> توجه: چون از polling استفاده می‌شود، سرویس باید همیشه روشن باشد (Worker).

## دستورات مهم ادمین

- `/admin` یا دکمه پنل ادمین → ورود به پنل
- افزودن اکانت: کد → قیمت → اطلاعات (یا skip)
- تأیید سفارش: دکمه ✅ روی پیام رسید
- ارسال اطلاعات: بعد از تأیید، دکمه «ارسال اطلاعات اکانت»
